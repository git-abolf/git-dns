# 🌐 DNS Master Pro

A powerful cross-platform DNS management and network utility.

## ✨ Features

- 🚀 Fast DNS configuration
- 🌍 Cross-platform support
- 🔍 DNS testing and diagnostics
- ⚡ Quick DNS switching
- 🛡️ Network and connectivity tools
- 🖥️ Windows executable available
- 🎨 Clean and user-friendly interface

## 🖥️ Windows

A ready-to-run Windows version is available in the Releases section.

Download the latest version and launch DNSMasterPro.exe.

- DNS / Network utilities
